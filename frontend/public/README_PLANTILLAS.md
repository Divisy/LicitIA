# 📋 Plantillas de Experiencias

## 📍 Ubicación de las Plantillas

Guarda tus archivos Excel en esta carpeta (`frontend/public/`):

### Archivos Requeridos:

1. **`plantilla-experiencias.xlsx`** - Plantilla vacía para que el usuario la descargue y complete
   - Esta es la plantilla que se descarga cuando el usuario hace clic en "Descargar Plantilla"
   - Debe tener las columnas correctas pero sin datos (solo encabezados)

2. **`plantilla-ejemplo-experiencias.xlsx`** - Plantilla con datos de ejemplo
   - Esta es la plantilla que se carga automáticamente cuando el usuario hace clic en "Usar Plantilla de Ejemplo"
   - Debe tener las columnas correctas Y datos de ejemplo para demostrar cómo funcionan los matches

## 📊 Formato Requerido

Las plantillas deben tener estas columnas:

### Columnas Obligatorias:
- **OBRA** (obligatoria) - Descripción del proyecto

### Columnas Opcionales:
- **EMPRESA** - Nombre de la empresa
- **ENTIDAD CONTRATANTE** - Entidad que contrató
- **VALOR ACTUAL** - Monto del contrato
- **FECHA FINALIZACIÓN** - Fecha de finalización
- **CONTRATO No.** - Número de contrato
- **CATEGORÍA** - Categoría del proyecto
- **ÁREA DE LA INGENIERÍA CIVIL** - Área de ingeniería

## 💡 Recomendaciones para la Plantilla de Ejemplo

La plantilla de ejemplo (`plantilla-ejemplo-experiencias.xlsx`) debe incluir:

- **3-5 experiencias de ejemplo** relacionadas con:
  - Obras de construcción
  - Interventoría vial
  - Estudios y diseños
  - Supervisión de proyectos

- **Datos realistas** que demuestren:
  - Diferentes tipos de proyectos
  - Diferentes montos
  - Diferentes entidades contratantes
  - Diferentes fechas

Esto ayudará a los usuarios a:
1. Ver cómo funciona el matching
2. Entender el formato esperado
3. Motivarse a cargar sus propias experiencias

## 🚀 Después de Agregar las Plantillas

Una vez que agregues los archivos Excel a esta carpeta:
1. Los archivos estarán disponibles en `/plantilla-experiencias.xlsx` y `/plantilla-ejemplo-experiencias.xlsx`
2. El botón "Descargar Plantilla" funcionará automáticamente
3. El botón "Usar Plantilla de Ejemplo" cargará los datos de ejemplo automáticamente
